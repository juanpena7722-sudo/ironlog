## Summary

Adds the backend package `server/`: a Fastify 5 app with Zod-validated configuration, a global
error handler that emits RFC 9457 Problem Details, and `GET /api/v1/health`. PostgreSQL 16 runs
through Docker Compose with `ironlog_dev` and `ironlog_test` databases, and CI gains a `backend`
job with a Postgres service. Later backend tasks build on `buildApp()`.

## Notes

- `fastify-type-provider-zod` (PRODUCTION_RULES §4.3) is not installed yet. No route validates
  input in TB01, and v7 requires `@fastify/swagger` as a peer dependency. Route handlers can
  throw `ZodError` directly, and the error handler maps it to 400.
- TypeScript is pinned to `~6.0.3` because `typescript-eslint` does not support TypeScript 7 yet.
- `DATABASE_URL` and `JWT_SECRET` are validated but not used until TB02 and TB03.
- `server/db/init.sql` runs only when the Postgres volume is first created. An existing volume
  from before TB01 needs `docker compose down -v` to get `ironlog_test`.
- The root `eslint.config.js` change is outside the files TB01 names. It is needed so that root
  lint does not scan `server/`, which has its own config.
