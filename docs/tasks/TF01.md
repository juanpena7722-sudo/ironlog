# TF01 — Frontend test harness and existing-logic tests

- **Status:** Verified, PR #11 awaiting owner approval
- **Branch:** test/tf01-test-harness
- **Date:** 2026-11-11

## Summary

Adds the frontend test harness: Testing Library, user-event, jsdom and MSW v2 with one setup
file. The existing logic in `src/utils.ts` and `normalize()` in `src/store.tsx` now has unit
tests, and every page has a smoke test. Route pages are lazy-loaded with `React.lazy` and
`Suspense`, so each page builds as a separate chunk.

## Notes

- `msw` is pinned to `^2`: `PRODUCTION_RULES.md` §4.2 requires MSW v2, and v3 needs
  TypeScript 5.9 or later.
- Exporting `normalize` adds one `react-refresh/only-export-components` warning in
  `src/store.tsx`. The rule is a warning only and already fired on that file.
- The `Suspense` fallback is plain `Loading…` text; loading, error and empty states are part of
  TF06.
- The 2 moderate `react-router` advisories (GHSA-wrjc-x8rr-h8h6, GHSA-337j-9hxr-rhxg) predate
  TF01; the fix needs `react-router-dom` 7.
- React Router v7 future-flag warnings appear on stderr during the page tests; they do not fail
  any test.
