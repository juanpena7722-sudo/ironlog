# TF00 — Foundation: tooling, shared schemas, CI

- **Status:** Verified, PR #1 awaiting owner approval
- **Branch:** chore/SH-01-foundation
- **Date:** 2026-11-08

## Summary

Adds the shared tooling every later task depends on: Prettier, type-check and test scripts,
Vitest with coverage thresholds, and a GitHub Actions workflow. Data shapes now live once as Zod
schemas in `shared/schemas.ts`; `src/types.ts` re-exports the inferred types, so the app is
unchanged. The task was created as SH-01, before the TF/TB ID scheme.
