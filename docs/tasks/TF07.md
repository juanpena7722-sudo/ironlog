# TF07 — End-to-end and accessibility suite in CI

- **Status:** Verified, PR #17 awaiting owner approval
- **Branch:** test/tf07-e2e
- **Date:** 2026-11-11

## Summary

A Playwright suite runs every critical journey from PRODUCTION_RULES §5 through the production
stack (gateway, API, PostgreSQL), in a desktop Chromium project and a 390 × 844 project, and
`e2e/a11y.spec.ts` runs axe on every page. `npm run test:e2e` builds the frontend, starts the
stack with secrets generated for the run and removes it afterwards. A new CI job runs the suite
and uploads the report when it fails. The suite found one serious axe violation on mobile, which
is fixed.

## Notes

- The mobile axe scan found `scrollable-region-focusable` (serious) on the Workouts Personal
  records table, which scrolls sideways at 390 px. It is fixed in `src/pages/Workouts.tsx` with
  a regression test.
- The suite uses the server's real rate limits. `waitForRateLimit()` waits for the next window
  when fewer than 60 requests are left, so a run can take longer than the usual 1.6 minutes if
  the window runs low.
- Ports 80 and 443 must be free on the machine that runs `npm run test:e2e`.
