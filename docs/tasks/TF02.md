# TF02 — API client and TanStack Query

- **Status:** Verified, PR #12 awaiting owner approval
- **Branch:** feat/tf02-api-client
- **Date:** 2026-11-11

## Summary

Adds the frontend API client and TanStack Query. `apiRequest` calls the fixed same-origin base
`/api/v1`, validates responses with the shared Zod schemas and turns Problem Details error bodies
into `ApiError`. The app is wrapped in a `QueryClientProvider` that retries once on 5xx only. The
Vite dev server proxies `/api` to the local API. No page uses the API yet.
