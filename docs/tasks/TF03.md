# TF03 — Auth screens and protected routes

- **Status:** Verified, PR #13 awaiting owner approval
- **Branch:** feat/tf03-auth-ui
- **Date:** 2026-11-11

## Summary

Adds the `/login` and `/register` pages and puts every other page behind a session check.
`useSession()` reads `GET /auth/me`; without a session the app redirects to `/login` and returns
to the original page after sign-in. Logout is in the navigation and Settings can delete the
account after confirmation and the password. The auth request schemas moved to `shared/` so the
forms and the API validate with the same rules and messages.
