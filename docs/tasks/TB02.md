- **Status:** Verified, PR #3 awaiting owner approval
- **Branch:** feat/tb02-db-schema
- **Date:** 2026-11-08

## Summary

Adds the PostgreSQL data model with Prisma 7 (`@prisma/adapter-pg`): `User`, `Goals`, `Workout`,
`Exercise`, `WorkoutSet`, `FoodEntry`, `BodyEntry` and `HealthEntry`, plus one committed `init`
migration. `buildApp()` exposes the client as `app.db` and disconnects it on close. Scripts cover
migrations, a test database reset and a demo-data seed. Tests run against `ironlog_test` with a
truncate helper.

## Notes

- `db:reset:test` was not run during validation: Prisma 7 blocks `migrate reset` when an AI agent
  invokes it. The owner verifies this script.
- The lowercase-email `CHECK` lives only in the migration SQL; Prisma does not model `CHECK`
  constraints. TB03 must lowercase emails before writing.
- The demo user's `passwordHash` is an empty placeholder until TB03 adds password hashing.
- `server/prisma/seed.ts` imports `src/demo.ts`, which pulls in React files, so the seed is not
  included in the server `typecheck`. It runs under tsx.
- `.gitignore`, `server/eslint.config.js`, `server/tsconfig.json`, `server/vitest.config.ts`
  and `.github/workflows/ci.yml` change only to support the generated client and the test
  database.
