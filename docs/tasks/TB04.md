- **Status:** Verified, PR #5 awaiting owner approval
- **Branch:** feat/tb04-workouts-api
- **Date:** 2026-11-08

## Summary

Adds the workouts API: list, get, create, replace and delete under `/api/v1/workouts`. Every
route requires a session and only touches the current user's workouts. Bodies and responses use
the shared `WorkoutSchema`, with exercises and sets kept in order. PUT replaces the workout and
its exercises in one transaction.

## Notes

- PUT deletes and recreates the exercises and sets, so their ids change on every replace. Clients
  must not keep exercise ids across a PUT.
- The default `from` is 90 days before the current UTC day, and it applies even when only `to` is
  given: `?to=` with a date older than that returns `[]`. Clients that want an older range must
  send `from`.
- Weights are stored as `Decimal(6,2)`, so values with more than 2 decimals are rounded.
- The list has no pagination; the date range is the only limit on its size.
